이렇게 수정하세요

  1. 선택: 글·표·카드·그림·선·화살표 클릭. 카드 안 글자는 따로 선택. 겹친 요소는 오른쪽 목록에서 선택
  2. 여러 개: Shift+클릭으로 추가·제외하거나 빈 공간에서 드래그. Ctrl+A로 전체 선택
  3. 글 수정: 더블클릭. 이동은 선택 테두리 위 ‘이동’을 끌거나 방향키 사용
  4. 그룹: 2개 이상 선택 후 ‘그룹화’. 하나를 클릭해 전체 선택. 그룹 안 글자는 더블클릭으로 개별 수정
  5. 텍스트 크기: 대각선 모서리는 글자·상자 비율 조절. 좌우 가운데 손잡이는 글자 크기를 유지하고 상자 너비·줄바꿈 조절
  6. 사진: 선택 후 오른쪽 ‘사진 자르기’. 원본에서 영역을 드래그하고 적용. ‘자르기 해제’로 원본 전체 표시. 겹친 사진은 오른쪽 목록에서 선택·삭제
  7. 장표 삭제: 왼쪽 장표별 ‘삭제’ 또는 목록에서 장표 선택 후 Delete. 실행 취소 가능
  8. 자동 맞춤: 다른 요소의 가장자리·중앙·간격에 맞춤. Alt를 누르거나 상단에서 해제
  9. 잠금·숨김: 오른쪽 설정에서 적용. 해제·표시는 아래 요소 목록에서 선택
  10. 저장: 자동 임시저장 + ‘편집 파일 저장’. 발표하거나 HTML 내려받기

Ctrl+C/X/V 요소 복사·잘라내기·붙여넣기 · Ctrl+Shift+C/V 장표 복사·붙여넣기 · 글 수정·입력칸에서는 텍스트 단축키 유지

Ctrl+G 그룹화 · Ctrl+Shift+G 그룹 해제 · Ctrl+Z 취소 · Ctrl+Shift+Z 다시 실행 · Ctrl+D 복제 · Delete 삭제 · Shift+방향키 10px 이동 · Esc 선택 해제
